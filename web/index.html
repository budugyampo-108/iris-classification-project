About this project

This application is an end-to-end machine-learning system built for a university assignment. It trains a Random Forest classifier on scikit-learn's Iris dataset (150 samples, 3 species, 4 numeric features) and exposes it through a REST API.

Model

Random Forest, 200 trees, stratified 80/20 split.

Backend

FastAPI with /api/metrics and /api/predict.

Web

This responsive interface, served as static files on Vercel.

Mobile

React Native / Expo app using the same live API.
